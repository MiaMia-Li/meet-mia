# Koda Flow Management System

A no-code platform for building and managing automated enterprise workflows, built at Kuaishou.

**Role:** Frontend Lead Developer  
**Team:** 6 developers (2 experienced + 4 fresh graduates)

## What It Does

Enables enterprise users to design complex automated workflows through a visual drag-and-drop interface, without writing code. Integrates with internal business systems and supports full lifecycle management.

## Key Technical Work

- Implemented modular MVC architecture separating view layer from business logic for maintainability and extensibility
- Used Redux for managing global state across dynamic connector states, connection flow structures, and real-time runtime data
- Integrated X6 open-source library for the drag-and-drop canvas interface
- Built dynamic form rendering: connector configuration parameters mapped to form item types, enabling automatic form generation and reducing connector creation workload
- Defined clear API specifications with the backend team for smooth data exchange
- Used phased development: core functionality first, then gradual expansion to mitigate risk

## Outcome

Successfully launched within a tight timeline. The platform's modular architecture enabled future feature expansions after launch.
