# PageGenAI

An AI pipeline that converts text, screenshots, or templates into fully built web pages — reducing page build time from hours to minutes (**10× speed improvement**).

Built independently as a solo project alongside SnapStory AI.

## What It Does

Users input text descriptions, paste a screenshot of an existing page, or select a template. The AI pipeline generates a complete, deployable web page.

## Key Work

- Owned full-stack design, development, and deployment end-to-end
- Built the AI generation pipeline integrating LLM and layout reasoning
- Focused on reducing the time-to-page for non-technical users

## Technologies

Next.js, TypeScript, OpenAI API, TailwindCSS
